历史范围：本文记录证书固定与 HTTPS 加固前的实验版本。文中的 HTTP、
当时的测试数和包文件数属于该次快照；不能作为当前版本数量或新 TLS 链路
已实机验证的声明。现行部署要求见[安全迁移](../SECURE_SETUP.md)，当前
兼容性与待验证项见[支持矩阵](../SUPPORTED_DEVICES.md)。

设备：LG OLED65B8PUA，固件 05.50.70。使用已授权的现有配对配置，经 loopback HTTP 和 JavaScript SDK 调用常驻中枢。私有 IP、令牌、原始截图和个人应用数据未随记录公开。

## 已验证

- 状态：Disney+ 前台，以及音量、静音、电源、音频输出和输入列表，返回时间戳、来源和过期时间。状态通过串行轮询获得。
- 控制：切换静音并读回目标值，恢复原值后再次确认。没有改变最终音量或静音状态。
- 幂等：以同一客户端和幂等键重复提交相同静音动作，返回相同 operation ID、`created:false`，未执行第二次。
- 画面：`screen.observe` 经新中枢完成，客户端经单独鉴权帧接口取得真实 1920×1080 JPEG。一次样本 162,218 字节，目视为实际播放画面；未据此推定可信片名。
- 内部反馈：Disney+ 系统播放器 `playerType:mse`、`playStateNow:playing`、全屏、1920×1080。数据来自系统 ACB，不是 Disney+ 页面结构或业务接口。
- 收尾：通信、完成、截图、关闭覆盖层、恢复原应用和受控临时截图删除均确认。
- 事件：SDK SSE 收到设备状态和操作 created/updated，具有递增 cursor。
- 持续反馈：修复历史回放时的发送缓冲问题后，真机 SDK 会话收到192条历史及当前事件，并确认本次操作的新事件；离线测试另外验证150条大事件回放后继续接收新事件。
- 重启：所有者接口优雅停机再启动，原音量操作及其幂等键仍在，重复请求返回原 confirmed 操作，未再次派发。
- 权限：只读临时授权可读状态，控制、观察和帧读取分别拒绝；撤销后状态请求也拒绝。

## 限制

本次没有穷举所有动作、编码、深链或其他设备。观察是临时事务，不能连续推送视频；应用前台与系统 `playing` 不保证指定影片已经播放。未取得 Disney+ DOM、可信标题字段、账号信息或 root。

离线测试另覆盖过期授权、跨设备范围、跨客户端操作访问、队列撤权、时限、重启不重放、未知结果、图片保留、Host/Origin、路径/网址限制和 SQLite 原子记录。离线测试不代替硬件证据与独立安全审计。

最终本机检查：221项测试，220通过、0失败、1项POSIX专用测试在Windows跳过；机型/证据校验与39文件打包边界检查通过。未公开发布。
